# 第 61 轮 · 过期检出路径的说明

当打开过的工作树已无法定位时，复核行用「上次检出路径」保留原信息，并引导用户先核对 Git 当前检出位置。打开结果与本次所选工作树的仓库、Host 和实例关联。同一路径重新登记的工作树需要自己的打开身份，先前记录留在原分支复核中。

保留原来等宽、可选取的路径，复用行内状态及时解释变化。只保留成功文案会使用户把上次打开当作现况，隐藏路径则会带走排查信息。选择继续展示路径及其时点。
