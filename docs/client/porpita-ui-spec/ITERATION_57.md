# 第 57 轮 · 主工作台的 Space 返回入口

用户从 Space 复核打开占用分支的工作树后，通常要留在主工作台检查或切换 Git 分支。原复核仍在独立窗口。第 55 轮主工作台实况只有常规资源入口，用户需要自行切换窗口才能确认回到哪一项。 [原工作台](evidence/iteration-54-56-space-en/i55-branch-open-checkout.png)

采用工作台状态栏的指示与短动作。主窗口确认打开该工作树后才出现「返回 Space 复核」。返回期间仍按同一复核，当复核结束时撤下。复用状态栏密度切换和图标模式，窄窗继续保有可访问名称。常规的磁盘使用入口继续为新检查提供入口。

短暂通知适合传达已打开结果。修复分支占用可跨越多次操作，状态栏更适合呈现此期间可用的返回动作。此处延续资源监视已有的 HardDrive 图标、标准 Button 与 Tooltip。
