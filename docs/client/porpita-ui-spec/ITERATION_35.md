# 第 35 轮 · 资源表行定位原工作树

资源管理器的本机汇总和资源树可以在组合式预览内使用。此前点击工作树行会启动原工作台定位，预览仍盖在上面。用户难以确认这次操作去了哪里。本轮把工作树定位的结果与可见视图切换接在一起。

保留现有资源树、工作树定位按钮和工作树激活逻辑。定位成功后关闭资源弹层并显示原工作台。暂时找不到目标时保留当前视图，在资源弹层显示反馈。原 Workspace 选择仍保存在预览里。

回放从 Studio Explorer 打开资源管理器。资源样本指向真实本机工作树，定位和返回使用实际应用操作。源码见 `use-resource-usage-actions.ts` 与 `resource-usage-session-rows.tsx`。对应 A.03.11、D.07.04 和 J13。

隐藏窗口的资源树沿用仓库诊断可见性夹具的渲染器信号。原生可见性门槛和采样入口保留，两组回放核对的是实际定位、视图切换与返回。 [定位及返回连续帧](evidence/iteration-33-35-port-resources-zh/resource-to-native-worktree/timeline.json)
