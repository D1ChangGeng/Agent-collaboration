# 第 46 轮 · 已确认清理的结果留在 Space

从审阅确认后，用户需要知道请求是否开始、哪些结果已确认，以及在哪里继续筛选。处理范围取该次确认的实际工作树清单。

| 阶段 | Space 反馈 |
| --- | --- |
| 开始处理 | 关闭确认窗口，将焦点交给搜索框。状态区域显示正在处理的项目数。 |
| 全部完成 | 显示实际完成的删除数量。列表与空间统计沿用工作树移除后的更新，搜索词和其他选择保留。 |
| 结果无法核实 | 显示无法确认的结果状态。 |

沿用 Space 选中栏的排版和背景，使用一条稳定的状态区域反馈结果。确认路径复用原工作树删除执行和已删除记录回写。
