验收维度按对象裁剪，但范围透明。主路径基准 1280×800，窄 820×580，原生最小 600×400，另测高 DPI、窄短窗和多显示器。源码列出 en、zh、zh-Hant、ko、ja、es、fr、pt、ru、tr、de；每个已发布语言都要看菜单、关键状态和翻译溢出，优先覆盖长标签和 CJK 混排。平台分别用各自交付包，不以 Windows 画面推断。高风险条件至少覆盖远端延迟、离线/撤权、数据规模、键盘与失捕。目标验收需要对象、状态与条件均绑定实际证据；保留项同样要核对原流程与改造后的回归，源码行存在不能替代操作。

矩阵分列局部证据、设计与源码状态、验收范围及下一步。局部回放按具体目标和条件判定。目标集成后继续按上述连续路径验证。
