# 第 84 轮 · 720px 下区分同前缀 SSH 主机

第 81–83 轮获用户确认。三个已登记的主机沿用同一前缀，分别以 atlas、beacon、cedar 结尾，实际地址和非默认端口各有区别。上一轮的 GNOME 720px 平铺窗口里，三行的别名和地址都被截短，失去了区分目标所需的后缀。1440px 基线可以读全。 [720px 基线](evidence/iteration-84-86-gnome-baseline/i84-baseline-beacon.png) · [基线记录](evidence/iteration-84-86-gnome-baseline/run.json)

沿用 SSH Hosts 的行、复选框、状态和操作按钮。使用同页工具栏的换行方式，让别名和地址保留完整字符，操作区在剩余宽度不足时换到同一行条目下方。目标是在 720px 下同时看见三条身份，宽窗口维持紧凑排列。

修订版在 720px 同时显示三个完整的别名和地址，1440px 宽窗中仍可在同一行查看别名及地址。连接前、连接成功和断开后都复核了窄窗的完整文字范围。 [修订后 720px](evidence/iteration-84-86-gnome-en/i84-tiled.png) · [修订后 1440px](evidence/iteration-84-86-gnome-en/i84-wide.png)
