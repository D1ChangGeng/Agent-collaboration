# 第 49 轮 · Space 保留分支的结果与入口

Git 可以移除工作树目录，同时保留含未合并提交的本地分支。原来的清理回执只显示目录结果，保留分支的复核入口在通知中。

- 最近一次工作树清理的结果继续按实际删除数显示。Git 回报保留的分支另列数量，右侧提供「复核保留的分支」。在窄窗按现有工具栏的换行布局排列。
- 入口与列表筛选独立。当前 Space 窗口持续累积经审阅清理所产生的待复核分支，以工作树、主机、Runtime、分支和原 HEAD 识别同一结果。收到分支删除成功回执后更新数量。关闭 Space 结束这一窗口内的结果记录，Git 分支继续由原仓库持有。
- 保留分支信息采用原 Git 清理回执。原分支清理设置和普通工作树入口仍按现有动作执行。Space 的筛选审阅使用结果栏承载分支结果，分支删除期间禁用重复复核，完成后更新可操作项。
