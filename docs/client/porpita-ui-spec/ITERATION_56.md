# 第 56 轮 · 释放检出后继续原复核

工作树在主窗口打开时，原 Space 窗口继续持有分支清单与选择。用户在相应工作树释放分支后，可从原复核确认提交。Git 继续按原 HEAD 与当前检出校验发出结果。

- 优先维持选项与当前 Dialog。跨窗打开本身只负责定位工作台。复核的关闭与操作结果仍采用前几轮的焦点和回执。
- 两个拒绝项各自处理。第一次确定删除后，仍被占用的条目和路径继续可复核。处理外部 checkout 后，再从同一入口提交最后一项。
- 沿用 Q.04 的复核窗口入场和既有状态栏更新。回放核对定位前后、一次确认完成及最后一项完成的稳定状态。
