# 第 22 轮：重启后恢复原工作空间和所选窗格

这轮从已保存的混合 Workspace 开始。关闭桌面客户端后，新进程通过「工作空间（预览）」回到同一对象、分屏比例和所选 Pane。两条 Native Chat 的未发送草稿由现有编辑器草稿机制还原，Workspace 档案保存会话引用与位置。

v2 引用保存 Host、配对版本、Worktree、原生会话 ID 和上次的 Tab 句柄。焦点由会话身份决定。普通断线和同一配对 Runtime 的进程重启保持引用；重新配对后，旧引用等待用户核对来源。版本号使旧构建能明确拒绝自己无法理解的新档案。读取合法 v1 时，明确补本机归属。下一次布局编辑原子保存 v2，损坏数据仍沿用第 12 轮的重试入口。 [本机冷恢复基线](ITERATION_12.md)

验收区分客户端与 Host 的进程边界：重启客户端时 Studio 继续运行；恢复到原 Pane 才核对内容、焦点与两份草稿。另外在真实客户端档案读取合法 v1 并触发一次可见的分屏编辑。关闭后再由可见的工作空间入口进入，是本轮的恢复路径。
