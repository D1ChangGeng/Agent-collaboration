# Agent Collaboration System v1.0.0 candidate

This candidate packages the Agent Collaboration System as a guided distribution
for local AI Harnesses and a private MCP connection path for a single installation
owner.

## Highlights

- AI-assisted environment inspection, guarded local setup and installation
  reporting.
- Project Management Root and Route workflows for durable collaboration state.
- Team, WorkItem, message, Inbox recovery, Source evidence and independent Review
  tools through the typed MCP surface.
- Codex and OpenCode setup with digest-checked setup and Runtime knowledge Skills.
- Linux Runtime service support with Windows Harness clients supported through an
  admitted Runtime connection.
- Owner-scoped ChatGPT access through OpenAI Secure MCP Tunnel, using the
  existing ACS principal and Grant.
- English and Chinese onboarding documentation, architecture diagrams and
  troubleshooting guidance.

## Distribution

The source-bound package contains the exact commit/tree, locked dependency
inventory, license references and per-file SHA-256 manifest. Rebuild the package
from a clean checkout with `scripts/build_release.py` and compare the generated
archive hashes with `SHA256SUMS.txt`.

## First use

Give the public repository link to Codex or OpenCode and ask it to inspect the
current release, run the guarded installation plan, adopt the project Management
Root, and report the observed Runtime Profile and ProjectContextPack. The
[Getting Started guide](GETTING-STARTED.md) supplies the prompt and the complete
Route, Team, WorkItem, Inbox and Review walkthrough.

For ChatGPT, the installation owner completes the current OpenAI Platform Tunnel
permissions and ChatGPT developer-mode connection. The Agent then verifies
`read_profile`, `list_projects`, `load_project`, a bounded write, denied access,
reconnect and Grant revocation against the exact project.
