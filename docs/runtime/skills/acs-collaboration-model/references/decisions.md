# Collaboration decision map

Use configure_team when existing Scope bindings need different AgentSlots,
roles, Grants, Policies, budgets or Harness requirements.

Reuse a WorkItem when goal, accepted state, constraints and baseline still
match. Revise it when authorized intent changes. Create a separate WorkItem for
independently acceptable output or distinct ownership.

Delegation assigns new or selected work. Handoff transfers an existing WorkItem
and carries source state, evidence, unresolved items and acknowledgement.

Use one Message for one addressable request. Parallel independent requests keep
distinct WorkItem or sub-work identity and may share correlation.
