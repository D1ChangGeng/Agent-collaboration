# ACS starter prompts

These prompts select Skills. They are user-facing examples rather than a second
workflow authority.

## Setup

Install and configure ACS for this project, including its Management Root, local
Harness MCP entries and the web connection plan.

## Project management

Continue managing this project: restore current context, summarize active work
and blockers, then advance the highest-priority authorized item.

Summarize this project's Routes, WorkItems, collaborators, source state,
reviews, blockers and next actions.

## Delegation

Delegate the following goal to suitable collaborators. Reuse valid existing work
when possible, otherwise create a WorkItem. Use asynchronous delivery and notify
me when results arrive: <goal>.

## Handoff

Hand off WorkItem <id> to <destination>. Include exact source state, evidence,
unresolved items, push status and required acknowledgement.

## Review

Perform an independent <architecture|engineering|evidence|finalization> review
of <candidate>. Bind the exact source baseline and submit structured findings.

## Finalization

Validate and finalize WorkItem <id>. Confirm integrated source, required reviews,
evidence, effect readback and unresolved items before acceptance.

## Recovery

Recover the interrupted collaboration for <target>. Reconcile Inbox, Session,
delivery receipts, source state and uncertain effects before resuming.

## Portfolio

Compare all authorized projects and report milestones, blockers, dependencies,
resource conflicts and recommended coordination actions.
