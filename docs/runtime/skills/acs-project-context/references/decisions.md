# acs-project-context: decisions

Choose from the actual caller identity, current contact/receiver configuration and active tool schema.

- Use the verified project_id and stable returned contact handles; names do not confer permission.
- Client, project Root and Route manager are management levels; ordinary collaborators are not another management tier.
- A new Native Session preserves Slot authorship and historical message relationships. Repository hints do not synchronize code.

Exact arguments and observed effects come from the running tool schema. Historical input, when needed for a transition, is in [the v6 archive](legacy-v6-decisions.md); it is not the current communication contract.
