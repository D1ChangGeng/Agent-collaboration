# Project and Route decision map

| Question | Durable object |
|---|---|
| Which product or access boundary? | Project |
| Which shared governance and Route registry? | Collaboration Root |
| Which long-lived goal or architecture line? | Route |
| Which authorization and knowledge boundary? | Scope |
| Which acceptable unit of work? | WorkItem |
| Which current reasoning instance? | external Session role projection |

Create a Route for a durable line with its own goal, decisions, knowledge or
source relationship. Create a WorkItem for a concrete deliverable within a
Route. A new window, Session, machine, branch or retry preserves existing
identity.

Cross-project analysis keeps separate project_id, Authority, revisions and
evidence freshness. Coordination creates explicit relationships or WorkItems in
each affected Project.
