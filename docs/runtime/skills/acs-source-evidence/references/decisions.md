# Source and evidence decision map

Choose the reader that can observe the intended target through its actual
connection and access. Machine tools serve current account files, including
repository edits, hidden files, binaries and paths outside a repository.
Native, Git and repository MCP tools retain their own reader contracts.

Before a machine read, inspect filesystem_context when the machine or account
is uncertain. Use select_filesystem for a session default or machine_id/cwd for
one call. Continue with the returned absolute path and cursor; its machine and
directory remain the target after the default selection changes. Record the
reported account, machine, path and observation time where they support a claim.

Load current management documents through load_project. If their location
changes, use configure_project with the current Project revision and read back
the resulting context. Resolve partial context through its missing paths and
ordinary read_file follow-ups.

Select a WorkItem.source_baseline when the work needs a chosen version. Owner
work can also start with omission or null. Use an eligible revise_work to change
or clear that selection; retain the source identity in Evidence already recorded
for a candidate. Record the reader, repository, branch, commit/tree and workspace
state that support each new claim.

For owner Review and acceptance, inspect the actual candidate and report its
commit/tree through source_readback. Verify that its Evidence and receipts agree
with that observed version. Repository edits require their own supporting facts
and byte identity in the candidate evidence.

Use the Source archive for a specific historical query. Discover recorded IDs
and views with list_sources, then select source_id and revision explicitly.
Continue at the captured view_revision. New work takes its version from an
explicit Agent decision.

Record commits, Push and receiver action independently of Message delivery.
Current access and explicit revocation govern new reads. Shared deployments
preserve their existing Scope, permission and version boundaries; historical
reference results retain their measured Profile and configuration.
