# Source and evidence decision map

Choose the reader that can observe the intended target through its actual
connection and access. Machine tools serve current account files, including
repository edits, hidden files, binaries and paths outside a repository.
Explicit Source tools serve Project repository observations and captured versions.
Native, Git and repository MCP tools retain their own reader contracts.

Before a machine read, inspect filesystem_context when the machine or account
is uncertain. Use select_filesystem for a session default or machine_id/cwd for
one call. Continue with the returned absolute path and cursor; its machine and
directory remain the target after the default selection changes. Record the
reported account, machine, path and observation time where they support a claim.

For Project Source reads, primary_source_id selects the product Source and
primary_source_root locates its preferred repository. Current Source reads resolve
the physical primary worktree and actual branch. Use source_root for another
configured readable current worktree. Choose execution Node placement separately.

Treat version suggestions and origin_hint.host/path as guidance. Use
current_readable_root for the Source provider's reading location and actual_source
for its captured readback. Review provider/root/commit/tree/view_revision/observed_at
alongside the observed repository, branch and workspace state.

Keep product source_observation and distinct management_source_observation
attached to their own context. An unavailable product default leaves product
observation and primary/version references null. Management instructions and
explicit management reads retain their purpose and access checks.

Select a fixed commit or captured workspace view when reproducible repository
bytes are needed. Source pagination uses the returned view_revision. A new current
Source read can observe newer edits; a machine read observes the current OS file.

Review and acceptance retain the actual candidate and source/evidence identity.
Record commits, Push and receiver action independently of Message delivery.
Current access and explicit revocation govern new reads. Shared deployments
preserve their existing Scope, permission and version boundaries.
