# Review and acceptance decision map

Use a new Review when candidate or baseline changes materially. Reviewer identity
must be independent where Policy requires it.

A finding records severity, affected resource, evidence, consequence and required
action. Decision remains bounded by sampling, environment and Evidence validity.

Acceptance evaluates the integrated baseline, required Reviews, tests, protected
effects, publication readback and unresolved items. Product-owner input is a
separate authenticated decision when Policy requires it.
