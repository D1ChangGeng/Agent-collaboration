# 00｜决策权威、范围收敛与目标定义

## 目标

保留 ACS 的受信独立通信主链和项目组织语义，借鉴 Orca 的 Harness 深度集成工程经验，提高真实 Native 状态接入、唤醒、正确送达和恢复的可验证覆盖，并为未来 Orca 原生客户端接入提供**通信相关的**完整后端契约。任何新能力必须在能力不具备时明确表示 `unknown` / `unsupported`，不虚构保证。

## 本版相对于 v1.0.0 的明确变更

| 旧包范围 | 本版处理 | 影响 |
|---|---|---|
| WP00→WP10 线性计划、template `not_started` | 改为**无阶段假设**的差异驱动实施 | 已完成验证保留，部分完成补缺口，未开始实施 |
| 40 R、96 T 全当首要硬交 | 仍保留完整追踪；区分 P0/P1/P2 与 legacy invariant | 不删正确性，改变验收归属 |
| 全部 35 HTTP 操作一律必交 | 仅 P1 子集是本轮客户端合同；P2 操作保持候选 | 去掉附件/草稿/搜索等强制前置 |
| 个人已读、偏好、跨设备草稿和二进制附件必交 | 作为 P2 可选独立模块，已实施的留存 | Core 不被产品体验阻塞 |

| 编排/Host 缺少公开接口时要求无 UI bridge | 保留明确宿主 port/鉴权/协议测试和 host-gap；禁止假装真实 Host 已接通 | 规范可落地，不虚报实装 |

## P0、P1、P2 的严格含义

- **P0（本轮核心必交）**：真实跨 Harness 通信的既有不变量回归与必需增强——能力探测、输入准入、Native 副作用调和、旧代次隔离、持续投递、受权恢复、最小诊断。仅在实际环境支持时宣称新路径可用。没有改造缺口则不造代码。
- **P1（本轮独立必交里程碑）**：完整的 ACS 通信客户端服务：身份、联系人、只读会话投影、历史、消息/回复、状态、通知、实时快照/重连、权限、native linkage、宿主适配端口与 headless 集成消费者。不是完整 Native Chat Backend 或 UI 移植。
- **P2（本轮非阻塞）**：个人未读/已读、草稿同步、偏好/静音/归档、全文搜索、二进制附件服务、高级跨设备体验。已有功能不得破坏或删去；若独立开发并验证，可单独交付。

## 非目标

不引入 Task/Run/Dispatch/Gate 作为通信前置，不接管 Harness/Orca 的工作任务、原生 transcript、工具调用、Diff、审批、模型设置、Git 与 Worktree。不要展开产品优劣调研、新设计探索型 PoC、视觉设计、Orca UI 修改或新 Fork。本轮不需要上游 PR，也不自动进行远端生产切换、合并/Tag/Release。

## 不可缩减的正确性

原子提交、可信 sender、按 scope 授权、显示名与地址分离、`reply_to`、Inbox/Outbox、`message_only`、wait 不撤回、read 不消费、未知副作用不盲重、只读观察不产生 Native 副作用、接收 owner 单一、旧接收绑定不可执行新操作和跨项目私密隔离。参考 `docs/06_CORRECTNESS_AND_SECURITY.md`。

## 完成定义

Core P0 与 Client P1 **分别验收并可以先后完成**。非 P2 工具/字段增加必须有能力声明、权限、错误、预算、异常及回归；真实 Harness 只在具体支持的版本/OS/Host/授权组合下填 `qualified`。P1 的 Orca 端口能以 headless 测试验证，但真实 Orca 插件资格是独立结果，不因类型通过而称完成。
