# WP06｜最小原生UI扩展与P1/P2功能落地

依赖：WP05。相关规范以 docs 和 contracts 为准。

## 实施动作

1. 在现有组件/抽屉/设置内接入联系人、会话、消息、通知、阅读/草稿/搜索/附件。
2. 复用已有SDK的snapshot/events/reducer/paging，区别ACS与Native数据来源。
3. 实现SourceLink查看执行，关联真实input/turn而不是文本匹配。
4. 接通目标Host附件材料化与原生读取；现有原生Chat附件不回归。
5. 按原生基线检查键盘、IME、滚动、焦点、密度和响应体验。

## 需要交付

- 真实客户端通信与产品功能
- 少量自然UI扩展和可见执行关联

## 退出条件

核心消息和P2交互不用外部命令，不出现独立控制台。
