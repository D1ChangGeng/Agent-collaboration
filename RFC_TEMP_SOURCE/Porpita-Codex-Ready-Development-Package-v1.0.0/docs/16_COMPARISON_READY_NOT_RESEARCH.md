# 16｜为后续真实比较保留条件，不把本轮变成研究

最终产品是Porpita，不是“Orca与ACS后端选择器”。正式安装默认且正常A2A仅用ACS。不要让双后端同时控制同一会话。

保留固定Orca上游提交和独立profile，后续可在相同UI/模型/工作区条件下对比。它可以是单独baseline安装或开发构建，不要求把旧后端继续运送进Porpita发布产物。

本轮需要记录直接体验事实：正常任务中是否要人工转述、找联系人/状态是否自然、消息是否能关联执行、重开是否连续、原生工具/审批是否受干扰。无需统计显著性、模型编码质量竞赛或新的对比实验设计。

在完整客户端通过之前，不宣称ACS协作更好；在产品开发过程中也不因这个尚未研究的结论延迟打包交付。完成后再围绕真实体验确定下一代专属能力。
